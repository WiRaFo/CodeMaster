# Ручная проверка доступности (чек-лист для человека)

Автоматические проверки (axe в 5 темах, 10 ширин, 200 % текста, клавиатурные сценарии e2e) этого не заменяют:
axe находит около трети нарушений WCAG. Пункты ниже проверяются вручную; результат записывается в
[audit-log.md](../accessibility/audit-log.md) с датой, устройством и версией дикторa. **Пока не выполнялось.**

## Подготовка

- NVDA 2024+ с Firefox или Chrome (Windows); VoiceOver с Safari (macOS, iOS); TalkBack с Chrome (Android).
- Сайт с сидами `migrated, synthetic, demo`; язык интерфейса — по очереди kk и ru.

## Страницы и что проверить

| Страница | Проверка |
|---|---|
| Главная `/kk` | Диктор читает язык страницы казахским голосом (атрибут `lang`); ссылка «Перейти к содержимому» первая по Tab; список ориентиров: шапка, навигация, main, подвал |
| Каталог `/ru/catalog?q=протокол` | После поиска объявляется число найденных документов (aria-live); фильтры читаются как группы флажков с числами; на телефоне диалог фильтров удерживает фокус, Esc закрывает и возвращает фокус на кнопку |
| Карточка документа | Шифр читается полностью («Ф. 1, Оп. 1, Д. 1»), кнопка копирования сообщает о результате; просмотрщик: кнопки листания и масштаба с понятными названиями, номер страницы объявляется |
| Карточка с ограниченным доступом | Сообщение об условиях доступа прочитано до перехода к метаданным; нет пустых ссылок на копию |
| Выставка | Экспонаты листаются, номер экспоната и их общее число объявляются; у изображений есть альтернативный текст |
| Филиалы | Карточки — заголовки третьего уровня; пометка «Сведения уточняются» читается; кнопка определения местоположения сообщает об отказе в доступе |
| Помощник | Ответ появляется в журнале и объявляется (aria-live), фокус остаётся в поле ввода |
| Отзыв | Пустая отправка: фокус на сводке ошибок, каждая ошибка связана с полем |
| Панель доступности | Каждая настройка объявляет своё состояние; «Сбросить» возвращает исходный вид |
| Панель управления `/admin` | Вход: ошибка читается; таблица документов с заголовками столбцов; диалоги подтверждения — alertdialog с фокусом на безопасной кнопке |

## Общие проверки

- Масштаб браузера 400 % на 1280 px: нет горизонтальной прокрутки текста (WCAG 1.4.10).
- Windows «Высокая контрастность» (forced colors): границы кнопок и фокус видны.
- Навигация только голосом (Voice Control на macOS/iOS): видимые подписи кнопок совпадают с их доступными именами (WCAG 2.5.3).
- Перевод страницы в браузере не ломает вёрстку.
