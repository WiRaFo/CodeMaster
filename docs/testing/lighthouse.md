# Lighthouse (ЭТАП 14, 2026-11-10)

Требование ТЗ §7.2, с. 16 — не ниже 80 по производительности и доступности.

**Как измерено:** Lighthouse 13.6.0, Chromium 1243 headless, `bash frontend/scripts/lighthouse.sh`
(production-сборка через `vite preview` на 127.0.0.1, API и база на той же машине, сиды `migrated, synthetic, demo`).
Мобильный режим — эмуляция телефона с замедлением сети и процессора по умолчанию Lighthouse, десктоп — `--preset=desktop`.
Ограничения: нет сжатия gzip/brotli и HTTP/2 (их даст nginx), сервер локальный — на боевом стенде задержка сети будет больше.
JSON-отчёты: `/mnt/project-files/archive-vko/testing/lighthouse-2026-11-10/`.

## До исправления

Карточка документа (CLS 0,67–0,83), выставка (CLS 0,53–0,98), филиалы и история — производительность 75–90.
Причина: пока страница загружает данные, содержимое короткое и подвал виден на первом экране; после загрузки
подвал уезжает вниз — это сдвиг макета (CLS). Исправление: `main` не ниже высоты экрана (`min-h-screen` в `LangLayout`),
подвал изначально ниже первого экрана.
