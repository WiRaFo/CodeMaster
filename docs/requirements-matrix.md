## Условные обозначения

**Обязательность:**
- `О` — обязательно по ТЗ («необходимо», «должен», «обязательные элементы»).
- `Д` — дополнительно по ТЗ («допускается», «может», «при наличии», «необязательный модуль»).
- `Б` — требование только брифа, в ТЗ отсутствует; выполняется как решение команды, не как требование заказчика.
- `Ау` — вывод аудита текущего сайта; решение команды.

**Статусы:** `NOT STARTED`, `IN PROGRESS`, `IMPLEMENTED`, `TESTED`, `DEFERRED`, `BLOCKED`. `DEFERRED` в этой версии означает «предложено не делать до защиты»; окончательно решает пользователь.

**Правило статуса.** `IMPLEMENTED` — функция работает сквозь все слои (UI → API → БД) на реальных, а не заглушечных данных. Наличие кнопки или страницы не считается реализацией. `TESTED` — тест реально запускался, результат записан в `docs/testing/`.

**Приоритет хакатона:** `P0` без этого нет демонстрации; `P1` нужно для полноты; `P2` если останется время; `—` после хакатона.
