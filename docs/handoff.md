## Жёсткие ограничения (нарушать нельзя)

1. **Сайт только информационно-справочный.** На нём нет:
   - заявлений и архивных запросов;
   - заказов и справок онлайн;
   - официальных обращений;
   - платежей и прейскурантов;
   - личных кабинетов для отслеживания заявок.

   Для услуг сайт даёт только справочные страницы и ссылки на официальные каналы. **Разрешена** форма отзывов и предложений о сайте: она явно помечена как неофициальная, сообщения не публикуются, email посетителя нигде не показывается.
2. **Закрытые материалы (`closed`) никогда не попадают в публичный доступ.** Это касается API, поиска, прямых запросов, счётчиков и подсказок.
   - **Ограниченные (`restricted`)** показываются только карточкой с разрешёнными метаданными и условиями доступа. У них нет копии и расшифровки, а расшифровка не участвует в поиске.
   - Эффективный уровень доступа — самый строгий в цепочке подразделение → фонд → опись → дело → документ.
   - Закрытая, неопубликованная, несуществующая запись и неверный id дают **одинаковый** ответ `404 NOT_FOUND`.
3. **Нельзя выдумывать архивные шифры, факты и координаты филиалов.**
   - Демо- и синтетические данные всегда помечены: `data_origin` = `demo` или `synthetic`, префикс «[Демо]» или «[Синтетика]», значок в интерфейсе.
   - Перенесённые со старого сайта сведения (`migrated`) помечены как «уточняются».
4. Секретов в репозитории нет. Инфраструктура только локальная или своя, без обязательных зарубежных облаков.
5. **Статус `TESTED` в матрице ставится только по записанному результату проверки** (раздел §9 «Журнал проверок»). Не пиши, что тесты прошли, если ты их не запускал.
   - Не используй `any` без обоснования.
   - Не подавляй ошибки TypeScript.
   - Не делай фиктивных API.
6. Метки архивного шифра утверждены пользователем предварительно:
   - RU: `Ф. / Оп. / Д. / Л.`
   - KZ: `Қ. / Тізб. / Іс / П.`
   - EN: `F. / Inv. / File / Fol.` — это интерфейсные метки, их могут поменять после согласования с архивом.
   - Метки лежат в `ARCHIVE_CODE_LABELS` в `packages/shared/src/archive-code.ts`.
7. Доступность: WCAG 2.2 AA.
   - Фокус всегда виден.
   - Цели касания не меньше 44×44 px.
   - Нет горизонтальной прокрутки от 320 px.
   - Текст 200 % ничего не ломает.
   - Работают 5 тем.
   - На каждой странице один `h1`.
