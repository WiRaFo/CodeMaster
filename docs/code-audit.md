## Что исправлено

- `assertIfMatch(request, updatedAt)` в `http/errors.ts`: одна проверка оптимистической блокировки вместо семи копий с разными текстами.
- `ruFirst(list)` в `admin/admin-common.ts`: русский перевод или первый имеющийся.
- `CATALOG_READ` и `catalogBranchScope(staff)` в `admin-common.ts`: какие филиалы каталога видит сотрудник. Используется списком документов, сводкой и экспортом.
- `frontend/src/admin/format.ts`: языки контента и форматы дат панели. Время теперь везде по Алматы: в выставках оно выводилось по часам браузера.
- Порядок импортов в `admin.routes.ts`, подключение модулей панели собрано в одном месте.
- Тестовый клиент (`backend/tests/staff.ts`) разбирает JSON только при JSON-ответе и отдаёт текст и заголовки: нужно для проверки CSV.

## Что осталось и почему

| Пункт | Предложение | Почему не сейчас |
|---|---|---|
| Нет линтера (ESLint) и автоформатирования | Подключить `typescript-eslint` (recommended-type-checked) и Prettier, запускать в `npm run check` | Новая зависимость и массовое переформатирование перед защитой создают риск без пользы для показа |
| Крупные компоненты панели: `DocumentEditPage.tsx` (587 строк), `ExhibitionsAdmin.tsx` (548) | Разделить на форму, историю и блок действий | Покрыты e2e; переделка без новых функций |
| Типы ответов API во фронтенде (`lib/types.ts`) написаны вручную | Описать ответы Zod-схемами в `packages/shared` и выводить типы | Требует правки всех маршрутов; сейчас форма ответов закреплена тестами API |
| Нет CI | GitHub Actions: `npm run check` на каждый PR, e2e по метке | Нужен доступ к настройкам репозитория |
