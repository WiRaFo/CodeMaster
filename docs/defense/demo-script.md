# Сценарий демонстрации на защите (13.11.2026)

Длительность показа — 8–10 минут, затем вопросы. Все данные на стенде помечены: `[Демо]` — демонстрационные
материалы, `[Синтетика]` — тестовые фонды `TEST-*`, сведения с текущего сайта — «Сведения уточняются».
Реальных архивных документов в прототипе нет, и это нужно сказать в начале.

## Подготовка (за час до защиты)

```bash
docker compose up -d db                 # или локальный PostgreSQL 16
npm install && npm run db:migrate && npm run db:seed
npm run check                           # ожидается: shared 16, backend 174, frontend 100 — все зелёные
npm run dev:api                         # терминал 1, http://127.0.0.1:3000
cd frontend && npx vite build && npx vite preview   # терминал 2, http://127.0.0.1:4173 (production-сборка)
```

- Пароли сотрудников — только в `backend/.env` (`SEED_ADMIN_PASSWORD`, `SEED_DEMO_STAFF_PASSWORD`). На слайды и в чат их не выносить.
- Открыть заранее три окна: сайт `/kk`, приватное окно для `archivist@archive.local`, приватное окно для `moderator@archive.local`.
- Запасной вариант без сети и базы: скриншоты этапов в `/mnt/project-files/archive-vko/screenshots/stage-*/`.
- Прогон с нуля на чистой базе проверен 2026-11-10: миграции и сиды за 5 секунд, e2e на свежей базе — см. журнал проверок (матрица §9).

## Честно о том, чего нет

- Реальных фондов и сканов: каталог на синтетике, тексты «Об архиве» и «Посетителям» требуют сверки архивом.
- Импорта и экспорта описей (F-145), управления пользователями из панели, редактирования публикаций, страниц и FAQ в панели.
- Карты филиалов (нет подтверждённых координат), серверной отрисовки для SEO, JSON-LD.
- Проверки экранными дикторами — подготовлен чек-лист `docs/testing/manual-a11y-checklist.md`.
- HTTPS-стенда, антивируса ClamAV, резервного копирования по расписанию — описано в `docs/deployment.md` и архитектуре.

## Ответы на вероятные вопросы

- **Почему не LLM в помощнике?** Правила дают предсказуемый ответ и не могут «придумать» документ; доступ к закрытым записям исключён, потому что помощник вызывает те же публичные маршруты, что и сайт.
- **Как защищены закрытые документы?** Публичное чтение идёт только через представления `public_*_v` в базе; тесты проверяют API, поиск и прямые запросы.
- **Почему SPA, а не SSR?** Один разработчик и срок хакатона; Lighthouse SEO 100, но превью ссылок в мессенджерах без серверной подстановки не появятся.
